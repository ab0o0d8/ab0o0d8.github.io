About me

I'm Abdullah Mo'men Hussien Ali, a .NET backend developer from Egypt. Here is why I chose this path and where I want it to take me.

// why

Why .NET and Backend

I want to build the part of an application that people never see but everything depends on: the logic, the data and the rules that keep it working. C# and ASP.NET Core give me a clear, well-structured way to learn that properly, and .NET connects naturally to the cloud and DevOps path I plan to follow.

// like

What I like about Backend

I enjoy how backend work turns a problem into something concrete. I get to design the data, decide how each piece of logic fits together and check that the whole system behaves correctly. It rewards careful thinking and steady problem solving, which I like to practice.

// goal

My short-term goal

My short-term goal is to reach a good level in backend development. That means getting comfortable with C# and ASP.NET Core, working confidently with SQL Server, and building projects that show what I can do.
